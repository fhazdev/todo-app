2List types — 1a carried forward

Same shell as 1a. A list now has a type, and each type owns its own category set: Grocery list (fresh produce, bread & bakery, dairy, meat & fish, pantry), Movie & show list, Default list — and you can add your own type, which starts with one category you then build out. The category order inside a type is the “By category” sort for every list of that type. Live: open a list, tick items, add an item, change sort, create a list (pick type → name), open Types, add a type, add and reorder its categories.

2aTypes own the categories. Type shown as a tinted chip on the list card and under the list title; the sort sheet names which type's categories it is sorting by.

1Sprout — three directions for a shared todo list

Android, Organic tokens, same data in all three. Each one is live: sign in with Google or email, open a list, tick items done and back, add an item with a category, switch sorts from the sort menu, reorder categories in the category manager (that order is the custom sort), and see the members on the list header. They differ in layout structure and how categories are shown. Assumptions: a small household sharing a few lists, four user-defined categories, no per-item assignees.

1aFamiliar. Bottom tabs, one flat list, category as a coloured chip on each row. Custom sort drops category headers in place; completed items collapse at the bottom.
